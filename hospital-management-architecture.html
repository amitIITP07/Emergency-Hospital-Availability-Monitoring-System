Access: public no auth · user verifyToken (any role) · admin verifyToken + adminOnly · manual JWT verified inside the handler. No route uses hospitalOnly; a few handlers check the role inline (noted in the last column), but bed, blood and emergency writes only require a valid token.

Patient dashboard connects with io(API_URL, { timeout: 5000, reconnectionAttempts: 2 }), so it gives up quickly if Render is cold-starting and the page falls back to REST data from GET /api/hospitals/beds.

Collection names are Mongoose defaults (lowercase plural of the model name). All schemas use timestamps: true. Settings keeps a single document keyed "global".
